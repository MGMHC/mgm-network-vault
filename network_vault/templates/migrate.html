1. Export everything

One encrypted file (.nvault) containing switches, credential profiles, every stored backup, schedules, logs, users, settings and GitHub settings. It's safe to run while backups are running.

The export includes the key that unlocks the stored switch and GitHub credentials. Keep the passphrase somewhere safe, separately from the file. Without it, the export cannot be opened.

2. Import on the new server

Upload an export made on another server, then restart. This replaces everything on this server. The current data is kept in a pre-restore-… folder until you delete it.

Application package

The app code plus installers for a Windows server (installs a service) and for Linux/Docker. It contains no data, settings or keys, so it's safe to share with the server team.

{{ icon('download') }}Download app package (.zip)

Moving to a new server

  1. Download the app package and an export from this page.
  2. On the new server, unzip the package and run deploy\install-windows.ps1 as Administrator. On Linux, use docker compose up -d.
  3. Open the new server's address, sign in as admin/admin, then come to Export & migrate, import the file and restart.
  4. Check the dashboard. Then stop the service on the old PC so the switches aren't backed up twice.

Command line equivalents: python manage.py export|import|package.
