Settings

How to create the repository and token
  1. On GitHub, create a new repository (for example switch-configs), set it to Private, and leave it empty — no README.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under repository access, pick only that repository. Under permissions, set Contents: Read and write. Set an expiry date and note it down.
  3. Paste the repository's HTTPS address and the token here, tick Sync backups to GitHub, and save. The first sync copies your existing backups to GitHub, oldest to newest, so the repository starts with their full history.
